# Real-Time BMI Monitoring System

A digital logic based real-time BMI classification system using decoders and combinational circuits

This project implements a hardware-based BMI calculator using:
- 4-to-16 decoder (74154)
- OR gates (7432)
- 2-to-4 decoder (74139)
- LED indicators for BMI categories

**BMI Categories:**
- Underweight
- Normal
- Overweight
- Obese

  **Methodology**
- Height and Weight encoded as 2-bit inputs
- 16 combinations decoded using 74154
- OR logic generates 2-bit BMI code
- Final decoder activates corresponding LED
